# Bundled font licences

Both faces ship inside the app and both are under the SIL Open Font License 1.1, which
requires the licence to travel with the software.

| Face | Role | Licence |
|---|---|---|
| Martian Mono | Every number in the interface | [`Martian-Mono-OFL.txt`](Martian-Mono-OFL.txt) |
| Inter | Labels and body text | [`Inter-OFL.txt`](Inter-OFL.txt) |

Martian Mono is used for data because its tabular figures keep a percentage from shifting
the layout as it ticks. That is a functional requirement in a panel where numbers update
while the user is looking at them, not a stylistic preference.

Neither font is renamed or modified, so the OFL's reserved-name clause is not engaged.
